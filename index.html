FAQ

Aksar poochhe jaane wale sawaal

App free hai?

Haan. App free hai aur aapka garden data aapke phone mein hi rehta hai. Sirf AI diagnosis ke liye internet chahiye.

Kya app offline chalta hai?

Nursery browse karna, Mera Bagicha aur watering schedule offline chalte hain. AI doctor aur Pandit Ji chat ke liye internet zaroori hai.

AI diagnosis kitna sahi hota hai?

App har result ke saath confidence score dikhata hai. Ye salah hai, doctor nahi — serious bimari mein nursery expert se bhi pooch lein.

App kaise milega?

Abhi app ka APK build ho raha hai. Neeche diye number par message karein, install link bhej diya jayega. Code GitHub par public hai.

Apne paudhon ka doctor aaj hi

App install link, demo ya kisi bhi sawaal ke liye message karein. Source code bhi GitHub par hai — koi bhi dekh sakta hai.
